# Términos de Servicio de WestcolClipsAI Última actualización: 16 de octubre de 2026. WestcolClipsAI es un proyecto de software de escritorio diseñado para ayudar a procesar videos, generar clips verticales y preparar contenido para redes sociales. **Uso permitido:** El usuario es responsable de contar con los derechos y permisos necesarios para procesar y publicar cualquier video. **Integración con TikTok:** Las funciones de publicación estarán sujetas a la autorización del usuario, la aprobación de la aplicación y las condiciones de TikTok. **Uso responsable:** No se debe utilizar la herramienta para infringir derechos de autor, vulnerar la privacidad o incumplir las leyes aplicables. **Disponibilidad:** Las funciones pueden cambiar y no se garantiza la disponibilidad continua del servicio. **Contacto:** La información de contacto del responsable se publicará cuando se habilite un canal oficial de atención.

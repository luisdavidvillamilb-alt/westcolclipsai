# Política de Privacidad de WestcolClipsAI Última actualización: 16 de octubre de 2026. WestcolClipsAI es un proyecto de software de escritorio para procesar videos y preparar clips para redes sociales. ## Información que se utiliza La herramienta procesa los archivos de video que el usuario selecciona. Si se habilita una integración con TikTok, podrá utilizar los permisos de cuenta que el usuario autorice para las funciones solicitadas. ## Uso de la información La información se utiliza únicamente para las funciones que el usuario ejecute, como procesar videos y preparar o realizar publicaciones autorizadas. ## Almacenamiento y seguridad Los archivos procesados se guardan en el computador del usuario. Las credenciales y los tokens de acceso deben mantenerse privados y protegidos. No deben compartirse públicamente. ## Servicios de terceros La integración con TikTok está sujeta a sus políticas de privacidad, permisos y condiciones de uso. El uso de sus servicios se rige también por las políticas de TikTok. ## Derechos y contacto Para solicitar información sobre privacidad o plantear una inquietud, el usuario deberá disponer de un canal de contacto oficial del responsable del proyecto. ## Cambios en esta política Esta política podrá actualizarse si cambian las funciones o el tratamiento de la información de WestcolClipsAI.
